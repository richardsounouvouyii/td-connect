# td-frontend

Dépôt Git autonome du site TD (React). L’API est dans un AUTRE dépôt : `td-api`.

1. Ouvrir ce dossier **seul** dans Cursor.
2. Lire `AGENTS.md`, `ARCHITECTURE_FRONTEND.md` et `CAHIER_DES_CHARGES_TD.md`.
3. Débuter uniquement par la phase 0.
4. Configurer `VITE_API_BASE_URL` pour joindre la Gateway en local.
5. Travailler sur un dépôt Git différent de `td-api`.

## Commandes

```bash
npm install
npm run dev
npm run build
npm run test
npm run lint
```

## Premier prompt Cursor

« Lis les trois fichiers de consignes. Initialise uniquement le dépôt `td-frontend` (React, TypeScript, Vite, Tailwind v4), en respectant l'architecture feature-first et les contraintes responsive. Ne crée aucun backend. Après chaque réponse, fournis tes recommandations UX, techniques et de sécurité. »
